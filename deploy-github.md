# GitHub Upload – schnellste Variante

Wenn Git auf deinem Computer installiert ist:

```bash
git init
git add .
git commit -m "Initial XAU/USD live analyzer"
git branch -M main
git remote add origin https://github.com/DEIN-NAME/xauusd-live-analyzer.git
git push -u origin main
```

Danach das Repository bei Render als Web Service verbinden.
